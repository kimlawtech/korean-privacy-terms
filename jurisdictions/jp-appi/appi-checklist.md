# APPI 필수 공개 항목 체크리스트

## 프라이버시 정책 (プライバシーポリシー)

### 第32条 보유개인데이터 관련 공표 사항 (필수)

- [ ] 事業者の名称 (사업자명)
- [ ] 事業者の住所 (소재지 주소)
- [ ] 代表者の氏名 (대표자 성명)
- [ ] 個人情報の利用目的 (이용 목적)
- [ ] 苦情の申出先 (고충처리 창구 — 담당자명·전화·이메일)
- [ ] 安全管理措置の概要 (안전관리조치 개요)

### 第18条 이용 목적 특정·공표

- [ ] 취득 시 이용 목적을 명확히 특정
- [ ] 목적 범위 초과 이용 시 사전 동의 절차 명기

### 第27条 제3자 제공

- [ ] 제3자 제공 유무 명기
- [ ] 제공 시: 제공 상대방, 목적, 항목, 제공 방법 기재
- [ ] 옵트아웃 방식 이용 시: PPC 신고 번호·공표 URL 포함

### 第28条 해외 제3자 제공 (해당 시)

- [ ] 제공 국가 명기
- [ ] 해당 국가의 개인정보 보호 체제 설명 또는 링크
- [ ] 상대 사업자가 취하는 조치 내용

### 第33조~第39조 정보 주체 권리

- [ ] 開示請求 (열람 청구) 절차 및 수수료
- [ ] 訂正·削除請求 (정정·삭제 청구) 절차
- [ ] 利用停止請求 (이용정지 청구) 절차
- [ ] 第三者提供停止請求 (제3자 제공 정지 청구) 절차
- [ ] 청구 접수 창구 (이메일·우편 등)

### 要配慮個人情報 (해당 시)

- [ ] 수집하는 요배려개인정보 종류 명기
- [ ] 별도 동의 취득 방법 명기
- [ ] 법령 근거 (법령상 수집 허용 시)

### Cookie·トラッキング (쿠키·추적 기술)

- [ ] 쿠키 이용 목적
- [ ] 거부 방법 (브라우저 설정 안내)
- [ ] 광고 목적 쿠키 이용 시 광고사업자 목록 또는 링크

### 自動化された意思決定 (자동화된 의사결정, 해당 시)

- [ ] 자동화 결정 내용 설명
- [ ] 이용되는 데이터 종류
- [ ] 이의신청 방법

### プライバシーポリシーの変更 (개정 절차)

- [ ] 개정 시 사전 고지 방법 명기
- [ ] 시행일·개정일 표시

## 이용약관 (利用規約)

### 특정상거래법 표기 (전자상거래 서비스에 필수)

- [ ] 事業者の名称 (사업자명 — 법인격 포함)
- [ ] 代表者氏名 (대표자 성명)
- [ ] 所在地 (소재지 — 실제 주소, P.O. Box 불가)
- [ ] 電話番号 (전화번호)
- [ ] メールアドレス (이메일 주소)
- [ ] 販売価格 (판매 가격 — 소비세 포함 표시)
- [ ] 支払方法 (결제 방법)
- [ ] 支払時期 (결제 시기)
- [ ] 商品の引渡時期 (인도 시기)
- [ ] 返品·交換·キャンセル (반품·교환·취소 정책)

### 消費者契約法 준수 사항

- [ ] 사업자 면책 무제한 조항 없음
- [ ] 소비자에게 일방적 불이익한 조항 없음
- [ ] 손해배상액 상한 명기 (소비자계약법 제9조)

### 準拠法·裁判管轄 (준거법·재판 관할)

- [ ] 준거법: 일본법 (B2C는 消費者契約法 우선)
- [ ] 관할 법원 명기

### アカウント·サービス利用

- [ ] 계정 등록 요건
- [ ] 이용 자격·금지 사항
- [ ] 계정 정지·해지 조건

### 知的財産権 (지식재산권)

- [ ] 서비스 콘텐츠 저작권 귀속
- [ ] 사용자 생성 콘텐츠(UGC) 시 라이선스 범위
