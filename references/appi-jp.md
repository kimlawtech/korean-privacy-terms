# 일본 개인정보보호법(APPI) 체크리스트 및 참고 자료

## 법령 개요

- **법령명**: 個人情報の保護に関する法律 (個人情報保護法, APPI)
- **최근 개정**: 2022년 4월 1일 시행 (令和3年改正)
- **소관 기관**: 個人情報保護委員会 (PPC, Personal Information Protection Commission)
- **공식 가이드라인**: 個人情報の保護に関する法律についてのガイドライン (2022년 9월 최종 개정)
- **영문 참고**: https://www.ppc.go.jp/en/

---

## 핵심 개념 정의

### 個人情報 (개인정보, Personal Information)
생존하는 개인에 관한 정보로, 성명·생년월일 등으로 특정 개인을 식별할 수 있는 정보.
또는 個人識別符号(개인식별부호)가 포함된 정보.

### 個人識別符号 (개인식별부호, Personal Identification Number)
- DNA 염기서열, 얼굴 인식 데이터, 지문, 홍채, 정맥, 음성 패턴
- 여권번호, 기초연금번호, 면허증번호, 주민표 코드, 개인번호(마이넘버)

### 要配慮個人情報 (요배려개인정보, Sensitive Personal Information)
취급에 특별한 주의가 필요한 정보. **별도 옵트인 동의 필수**.
- 인종·민족
- 신조 (종교·사상·정치적 견해)
- 사회적 신분
- 병력
- 범죄 경력·피해 사실
- 신체·지적·정신 장애
- 노동조합 가입 여부
- 건강검진 결과
- 성생활·성적 지향·성 정체성 (가이드라인 추가)

### 仮名加工情報 (가명가공정보, Pseudonymous Information)
제3자 제공 금지 조건으로 내부 분석 등에만 이용 가능한 가공 정보 (2022년 신설).

### 匿名加工情報 (익명가공정보, Anonymized Information)
특정 개인 재식별 불가 수준으로 가공한 정보. 제3자 제공 가능.

## APPI 프라이버시 정책 필수 공개 항목

### A. 이용 목적 (第15条·第18条)
- **의무**: 수집 시 이용 목적을 특정하고 공표·통지
- 목적 범위 초과 이용 시 사전 동의 필요
- 공표 방법: 홈페이지 게재 (가장 일반적)

### B. 제3자 제공 (第27条)
원칙적으로 본인 동의 없이 제3자 제공 금지.
예외:
- 법령에 근거
- 생명·신체·재산 보호를 위해 동의 취득 곤란
- 공중위생·아동건전육성을 위해 동의 취득 곤란
- 국가기관 등의 협력 필요 시

**オプトアウト (옵트아웃) 제3자 제공** (제27조 2항):
- 본인이 거절할 수 있는 수단을 마련한 경우
- PPC에 신고 필수 (사전 신고제)
- 인터넷 공표 의무
- 要配慮개인정보에는 옵트아웃 불가

### C. 外国にある第三者への提供 (해외 제3자 제공, 第28条)
- 본인 동의 필수 (일부 예외)
- 예외: 동등 수준 국가 (EU 등 PPC가 지정한 국가), 충분한 체제 정비된 사업자
- 제공 시 정보 주체에게 다음 고지 의무:
  1. 상대국 개인정보보호 체제 정보
  2. 상대 사업자가 취하는 조치 내용
- **한국은 2024년 3월 PPC의 '동등성 인정' 결정 검토 중** (미확정 시 개별 동의 필요)

### D. 保有個人データ (보유개인데이터) 관련 공표 의무 (第32条)
- 사업자명·주소·대표자명
- 이용 목적
- 개인정보 취급 관련 고충처리 창구 (苦情の申出先)
- 인정개인정보보호단체의 명칭·주소·고충처리 연락처 (가입 시)
- 安全管理措置의 개요

### E. 本人の権利 (정보 주체 권리, 第33条~第39条)
1. **開示請求 (열람 청구)** — 3개 주 이내 응답 의무
2. **訂正・追加・削除請求 (정정·추가·삭제 청구)** — 필요 범위 내에서 조치
3. **利用停止・消去請求 (이용정지·소거 청구)** — 법 위반 시 의무적 조치
4. **第三者提供停止請求 (제3자 제공 정지 청구)**
5. **開示等の求めの手続 (청구 절차 공표)** — 서면 또는 전자적 방법 선택 가능

### F. 安全管理措置 (안전관리조치, 第23条)
- 組織的安全管理措置 (조직적 조치): 책임자 지정, 규정 정비, 감사
- 人的安全管理措置 (인적 조치): 교육, NDA
- 物理的安全管理措置 (물리적 조치): 입퇴관 관리, 기기 도난 방지
- 技術的安全管理措置 (기술적 조치): 접근 제어, 암호화, 로깅

**종업원 수 100명 이하 중소기업 특례**: 安全管理措置 설명 간소화 가능

### G. 個人情報保護管理者 (개인정보보호 관리자)
APPI는 DPO 제도 없음. 대신 **개인정보보호 책임자(管理者)**를 내부적으로 지정 권장.
프라이버시 정책에 공표 시 고충처리 창구 역할 겸임.

## APPI 이용약관 관련 법령

### 消費者契約法 (소비자계약법)
- 소비자에게 불이익한 조항 무효화 규정
- 損害賠償額の予定条項 (손해배상액 예정 조항) 제한
- 解除権の放棄条項 (해제권 포기 조항) 무효

### 特定商取引法 (특정상거래법, 통판법)
**전자상거래 서비스에 필수** (제12조, 제12조의2~12조의6):
- 事業者の名称 (사업자명)
- 所在地 (소재지)
- 電話番号 (전화번호)
- 販売責任者 (판매책임자)
- 商品名·価格 (상품명·가격)
- 支払方法 (결제 방법)
- 引渡時期 (인도 시기)
- 返品・交換·キャンセル (반품·교환·취소 정책)
- クーリング・オフ (쿨링오프) — B2C, 특정 상거래에 한정

### 電子消費者契約法 (전자소비자계약법)
- 확인 화면 제공 의무 (클릭 전 내용 명확화)
- 操作ミス無効 (조작 실수 무효) 규정

### 不正競争防止法 (부정경쟁방지법)
영업비밀·데이터 관련 조항 — 기밀 데이터 처리 서비스에 관련.

## 해외 사업자 (域外適用, 第166条)

APPI는 일본 국내에 있는 자를 대상으로 물품·서비스 제공을 수반하는 개인정보 취급에 **역외 적용**됨.
- 일본 사용자를 대상으로 하는 한국 기업에도 적용
- 해외 사업자는 일본 내 代理人(대리인) 선임 권장 (법적 의무는 없으나 PPC 지도 대상)
- 외국에서의 違反에 대한 勧告·命令은 관보 게재 후 공표

## 特定電子メール法 (특정전자메일법)

마케팅 이메일 발송 시:
- 수신자 사전 동의 (옵트인) 필수
- 配信停止 (수신 거부) 방법 명기 의무
- 発信者情報 (발신자 정보) 표시 의무

## APPI vs GDPR vs PIPA 비교

| 항목 | APPI (일본) | GDPR (EU) | PIPA (한국) |
|------|------------|-----------|------------|
| 이용 목적 | 특정·공표 의무 | 법적 근거 명시 필수 | 처리 목적 필수 명시 |
| 민감정보 | 要配慮 (사전 동의) | Special Category (Art. 9) | 민감정보 (별도 동의) |
| DPO | 없음 (관리자 권장) | 의무 (일부) | CPO 의무 |
| 옵트아웃 제3자 제공 | 가능 (신고 필요) | 불가 | 원칙 불가 |
| 해외 이전 | 동의·동등성·체제 | SCCs·Adequacy·BCRs | 동의·계약 조치 |
| 아동 기준 | 15세 (가이드라인) | 16세 (13~16 회원국 설정) | 14세 |
| 과징금 | 최대 1억엔 | €20M / 매출 4% | 매출 3% (2026.9~) |
| 정보 주체 권리 | 5종 | 8종 | 5종 + 전송요구권 |
| 익명화 | 匿名加工情報 제도화 | 익명화 시 적용 제외 | 익명정보 |
| 가명화 | 仮名加工情報 (2022) | 가명처리 (Art. 4) | 가명정보 (2023) |

## APPI 프라이버시 정책 필수 항목 체크리스트

작성 완료 후 아래 항목 전부 포함 여부 확인:

- [ ] 事業者の名称·住所·代表者名 (사업자명·주소·대표자명)
- [ ] 個人情報の利用目的 (이용 목적)
- [ ] 第三者提供に関する事項 (제3자 제공 관련 사항)
- [ ] 外国への第三者提供 (해외 제3자 제공, 해당 시)
- [ ] 保有個人データの開示等の手続 (보유 개인데이터 열람 등 절차)
- [ ] 安全管理措置の概要 (안전관리조치 개요)
- [ ] 苦情の申出先 (고충처리 창구)
- [ ] 要配慮個人情報の取扱い (요배려개인정보, 해당 시)
- [ ] 自動的な意思決定·プロファイリング (자동화 결정, 해당 시)
- [ ] Cookieその他の技術 (쿠키 등 기술 설명)
- [ ] プライバシーポリシーの変更 (개정 절차)
